# Risk Register

| ID | Risk | Impact | Mitigation | Status |
|---|---|---|---|---|
| R-001 | The starting repository is one static HTML file with no Git history or backend | High | Preserve it unchanged as UX reference; establish contracts before migration | Active |
| R-002 | UI simulation may be mistaken for runtime capability | High | Label implementation status from evidence only; delete/disable simulated completion paths as native slices replace them | Active |
| R-003 | Event schema changes can make stored runs unreadable | High | Version every event; migration tests; unknown-event quarantine; snapshot schema version | Active |
| R-004 | Crash between side effect and event commit can duplicate tools | Critical | Persist intent/result and idempotency keys; reconcile only exact observable file effects after SQLite reopen; classify ambiguous mutating calls as `RECOVERY_NEEDS_INTERVENTION` and reject automatic retry; deterministic failure injection covers write-happened/completion-missing restart | Mitigated for provable file effects; ambiguous effects fail closed |
| R-005 | Frontend IPC could become arbitrary shell/filesystem authority | Critical | Narrow commands, schema validation, policy checks, path normalization, no generic execute command | Active |
| R-006 | Imported skills/plugins can contain scripts, binaries, symlinks, or traversal | Critical | Bare-object quarantine, no checkout/execution, exact commit/object pinning, bounded inventory, unsafe-path rejection, permission preview, explicit component install, immutable rollback snapshots | Mitigated M5 |
| R-007 | Provider secrets leak into events/logs/crash data | Critical | OS keyring references, structured redaction, taint tests, never serialize credential values | Mitigated M3 |
| R-008 | Worker spawning bypasses parent permissions | Critical | Validate every Worker permission as a subset of parent authority, restrict models to the allowed pool, and route native execution through the shared approval boundary | Mitigated M6 |
| R-009 | Cancellation stops UI state but leaves processes running | High | Windows Job Object owns the child tree; cancellation/timeout kill and await it; integration test proves a descendant cannot write after cancellation | Mitigated M2 |
| R-010 | Official runtime compatibility creates licensing or authentication-boundary violations | High | Bridge only through documented interfaces of the user's installed product; CLI owns authentication; no vendoring, cookie/token scraping, reverse engineering, or proprietary code reuse | Mitigated for Codex M5; Claude remains open |
| R-011 | Provider/network tests require credentials or paid usage | Medium | Deterministic fake provider for most tests; pause only for real credential acceptance tests | Active |
| R-012 | Windows release signing requires a certificate | Medium | Build and label `unsigned-rc` when secrets are absent; sign/verify the production executable before NSIS bundling and sign/verify the installer afterward; Stable workflow fails without authentic certificate secrets | Open external Stable gate |
| R-013 | Long goal can accumulate architectural drift | High | Short progress ledger, ADRs, milestone commits, full validation at every vertical slice | Active |
| R-014 | LunaScope distribution license is unspecified | Medium | Keep crates unpublished, state that visibility is not a license grant, and make the Stable workflow fail when root `LICENSE` is absent; do not choose a license in engineering work | Open owner decision / Stable gate |
| R-015 | Legacy V14 inline script/style prevents eliminating `unsafe-inline` from the desktop CSP | High | An explicit CSP now restricts sources and removes the former `csp: null`; continue extracting the remaining semantic-reference UI into bundled modules before public RC | Partially mitigated M9 |
| R-016 | Cancelling or closing an external bridge can leave descendants running | Critical | Visible cancel command, one active invocation, timeout/output bounds, Windows Job Object plus kill-on-drop, and an offline descendant-survival integration test | Mitigated M5 |
| R-017 | Parallel Workers overwrite the same file or contaminate each other's retries | Critical | Reject unordered overlapping write scopes; create a fresh commit-pinned worktree per Worker attempt; exchange only bounded immutable patches and artifacts; integrate in dependency order | Mitigated M6 |
| R-018 | A malformed Provider response is treated as verified work | High | Require schema-shaped JSON, impose an 8,000-character Planner contract, retry bounded compact repairs for truncated orchestration/tool JSON, fall back to an executable graph on repeated JSON EOF, require a typed `VerificationRecord`, downgrade verdicts that retain unresolved risks, and verify live output independently | Mitigated M9; live DeepSeek and browser-action acceptance recorded |
| R-019 | A graph patch submitted during execution races with a running Worker | High | State-guard every mode; apply queued revisions only at dispatch, retry revisions only at retry, clone topology changes into a separate run, persist cancellation before signalling, and reject unsupported hot restart of an active model call | Mitigated M6 |
| R-020 | A Domain Pack may advertise tools or evidence that the native Provider runner cannot actually execute | High | Treat pack tools as bounded routing intent, keep the Provider runner read-only, fail strict evidence gates on missing proof, and enable mutation only through isolated worktrees and declared ownership | Active M7 |
| R-021 | Adding several folders to a project may silently expand filesystem authority | Critical | Canonicalize and deduplicate folders, require exactly one explicit workspace, and scope native read/create/patch commands only to that workspace through the permission engine | Mitigated M8 |
| R-022 | A custom UltraNote instruction may suppress citations or bypass academic-integrity rules | High | Store it as presentation guidance only; fixed provenance, source-map, course-isolation, unresolved-policy, and homework-assistance constraints remain non-overridable | Mitigated M8 |
| R-023 | High-frequency Worker progress or variable node text can replace the graph DOM, reset the viewport, overlap nodes, or detach edges | Medium | Keep graph structure stable, patch Worker states in place, apply typed graph geometry after mount, key viewports by a topology fingerprint, rebind resize observation after route remounts, use fixed node geometry and matching edge anchors, clamp graph text, fit only a new or automatically managed graph, and validate packaged-WebView layouts at multiple DPI-aware window sizes | Mitigated M9 |
| R-024 | A model may ignore an explicitly required project root and scatter deliverables across the workspace | High | Parse a safe explicit root such as `sorting-visualizer/`, convert it into every mutating Worker's hard write scope, repeat it in Worker prompts, and assert the final required tree in the live release canary | Mitigated M9 |
| R-025 | An autonomous Verifier/repair loop can consume unbounded time or repeat the same ineffective fix | High | Persist each repair as a new run and allow unlimited progressing generations; preserve completed work and pause as `NeedsIntervention` only after three consecutive generations retain both the same fatal fingerprint and the same file/test/evidence fingerprint, or at an explicit budget, permission, cancellation, or unrecoverable-environment boundary | Mitigated M9 |
| R-026 | A patch artifact can escape its data root or exhaust the Changes view | Critical | Canonicalize the stored patch path below the fixed LunaScope data root, accept only recorded `text/x-diff`, cap bytes and lines, and return a read-only typed diff projection | Mitigated M9 |
| R-027 | Provider-generated English prose leaks through Chinese child-Agent and verifier surfaces | High | Enforce reply language in every prompt/schema, perform bounded structure-preserving rewrites, and localize or contain remaining human-facing prose while preserving code and identifiers | Mitigated M9 |
| R-028 | A bundled upstream Skill license conflicts with the intended distribution model | High | Pin every source revision, bundle complete license text, maintain an explicit source manifest, reconcile stale system files, and block commercial packaging of CC BY-NC packages unless separately licensed | Open for commercial release; disclosed for noncommercial RC |
| R-029 | A selected Skill references unavailable files or uses its documentation to escape the Skill root or trigger code | Critical | Preserve upstream package layout, resolve only UTF-8 resources below the fixed discovered root, support explicit relative-link bases, reject symlinks/traversal/oversized files, allow only selected catalog IDs, and keep scripts/hooks read-only and inert | Mitigated M9 |
| R-030 | Long multi-Agent work loses the original definition of done after delegation or context compaction | High | Persist 3-12 task-wide acceptance criteria in the Rust plan, inject them into every Worker, run a bounded pre-dispatch plan quality gate, preserve structured evidence checkpoints, and require final criterion-mapped independent verification | Mitigated M9 |
| R-031 | Uploaded documents contain oversized archives, unsupported binaries, prompt injection, or private visuals that are sent to an incapable Provider | Critical | Canonicalize explicit user-selected files, cap count/per-file/total/extracted/image bytes, accept an extension allowlist, keep content inert, extract only bounded OOXML media, label source content below system authority, and send binary visual blocks only to a configured vision-capable Provider after the existing Provider consent gate | Mitigated M9 |
| R-032 | A model-generated syllabus structure invents a course rule or silently omits an important policy | High | Instruct the Orchestration model to extract only supported facts, persist ambiguities, keep the revision unconfirmed, store the normalized source beside it, and fall back to deterministic extraction on model/protocol failure | Partially mitigated; user confirmation UX remains open |
| R-033 | PDF export depends on a browser runtime or prints before Mermaid/math rendering completes | Medium | Use pinned local Mermaid/KaTeX assets, one-shot Edge with a bounded virtual-time budget, validate process exit and PDF signature, preserve Markdown/HTML on failure, and run a real PDF render plus visual inspection in release validation | Mitigated on supported Windows/Edge installations |
| R-034 | Full Access self-management is mistaken for permission to expose credentials or execute imported hooks | Critical | Expose only allowlisted typed settings/Skill tools, inspect settings without secrets, validate routing/model contracts, quarantine and pin GitHub content, install only Skill components, and keep scripts/hooks inert | Mitigated M9 |
| R-035 | Long conversations disappear after a task, exceed localStorage, or overflow a Provider context window | Critical | Store user/final messages in SQLite before Provider work, bind plans to real project/thread IDs, hydrate from the native ledger, preserve immutable source messages, and use a threshold-triggered context-compression Agent plus recent uncovered messages | Mitigated M9 |
| R-036 | Browser verification becomes arbitrary Computer Use, mutates the project, accesses the network, or runs indefinitely | Critical | Expose only a workspace-local HTML verifier tool; select the browser in Rust, run actions in a 1,000-file/50 MiB temporary copy, proxy network to a closed loopback port, cap actions/waits/output, keep executable paths out of Provider prompts and copied diagnostics, and require an explicit local advanced-details action before showing them in Settings | Mitigated M9 |
| R-037 | A long-lived implementation context repeats diagnostics, exhausts its tool budget, or lets a final summary hide an untested hard requirement | High | Use role-specific bounded phases, checkpoint and hand off the real patch plus latest diagnostic evidence, inject exact retry failures, and require one evidence-bearing typed result per acceptance criterion before `verified` can survive scheduler settlement | Mitigated M9 |
| R-038 | Planning happens before a controllable Run exists, so the UI appears frozen and guidance/cancel can start duplicate work | Critical | Persist/register the Run before planning and share one controller across planning, execution, verification, and repair; treat every later Send as queued durable guidance | Mitigated M9 |
| R-039 | User cancellation is counted as Worker failure and triggers verifier repair or automatic retry | Critical | Classify user cancellation separately from dependency unavailability and execution failure; suppress acceptance enforcement, verifier repair, and retry after cancellation | Mitigated M9 |
| R-040 | Dynamic supervision blocks Worker tool progress or reports a replan without changing the graph | High | Run supervision asynchronously with single-flight/budget limits; persist every decision and apply only real queued-node patches or active-node guidance at safe boundaries | Mitigated M9 |
| R-041 | Provider model catalogs drift and an invalid reasoning effort makes an otherwise valid model unusable | High | Do not gate the control on an embedded catalog: accept one bounded Provider-native value per assignment, use blank for Provider default, and require an exact real model/effort test before every settings save | Mitigated M9; newly released Provider syntax can be entered without a LunaScope update |
| R-042 | A successful model test is reused after the Provider, model, endpoint, effort, or credential has changed | High | Persist attestations by the exact Provider-configuration/model/endpoint/credential-reference/effort tuple, clear them after relevant edits, require every saved tuple to have a valid compatibility test, and keep credential values out of the key and logs | Mitigated M9 |
| R-043 | A new Tauri command is registered in Rust but omitted from the main-window ACL, producing a misleading feature failure before backend logic runs | High | Generate the command permission, include it in `main-app-commands`, and fail a deterministic test when any registered command lacks its derived `allow-*` entry | Mitigated M9 |
| R-044 | A dense real-model project can remain valid but exceed a practical wall-clock test budget through slow planning, Worker, supervisor, and verifier calls | High | Limit planning to one request plus one compatibility continuation, keep all calls cancellable, persist per-phase latency/token/cache telemetry, send Workers only owned acceptance rows and bounded evidence previews, and retain smaller live canaries for release gating before making a 24-Worker stress case routine | Active M9 |
| R-045 | Requiring a planning model to emit extra progress tool calls can consume its convergence budget or reduce final graph quality | High | Expose exactly three first-turn tools, request one public progress record and one draft before submission, accept direct strict JSON, and project only the model's exact rationale/topology when progress tools are skipped; never request or synthesize hidden reasoning | Mitigated M9; real DeepSeek eight-Worker topology passed in 94.57 s |
| R-046 | Browser snapshot transitions can visibly overlap two full workspace pages and compound nested entry animations | Medium | Use one persistent DOM stage with a strict exit-swap-enter boundary, transform/opacity-only motion, rapid-request coalescing, nested-animation suppression, and a reduced-motion bypass | Mitigated M9 |
| R-047 | Slow first-message planning appears frozen, durable planning rationale disappears after recovery, or a late model event keeps the moon visible while paused or on another page | High | Show a neutral model-wait lifecycle until the first public model event, replay persisted planning activities with stable IDs, allow same-response graph submission, skip redundant review for a valid granular graph, gate the moon by Run phase and conversation route, and clear stale lifecycle records at boundaries | Mitigated M9; current DeepSeek topology canary completed in 94.57 s |
| R-048 | Runtime status prose is mistaken for model reasoning, or a Provider consumes its output budget in private reasoning and leaves the user-facing planning chain empty | Critical | Permit only Provider-native public summaries, model-authored commentary/progress, or the model's exact final rationale/topology in reasoning cards; require public reasoning before Worker actions; keep private reasoning replay-only; never run a separate synthetic briefing or fabricate content | Mitigated M9; real DeepSeek public-reasoning and graph-quality canary passed |
| R-049 | A side-effect-free Provider request fails transiently and either stalls silently or repeats a completed tool action | High | Separate transport retry from repair policy; retry only before any Provider output, persist every scheduled attempt, respect `Retry-After`, and never retry a settled tool call without state reconciliation | Mitigated M9 |
| R-050 | A long task loses ownership after restart or leaves orphaned background work | Critical | Persist Agent sessions, run leases, heartbeat, phase checkpoints, and last progress; clear leases on settlement; reconcile provable file effects; classify unrecoverable active tools as interrupted/NeedsIntervention; require reviewed multi-hour endurance evidence for Stable | Deterministic restart covered; Stable endurance evidence pending |
| R-052 | A missing, disconnected, or read-only data root prevents startup or silently splits persistent state | Critical | Central `DataPaths` resolution, per-user default, in-place legacy detection, atomic saved-root recovery, recovery-only IPC allowlist, dynamic narrow asset scope, replacement picker and restart; deterministic missing/custom/unwritable/legacy/containment tests | Mitigated; manual packaged recovery UX acceptance pending |
| R-051 | Custom desktop chrome or controls regress keyboard, focus, IME, DPI, or reduced-motion behavior while removing browser-native visuals | High | Keep semantic inputs, centralize custom select/dialog behavior, expose ARIA state and keyboard dismissal, reserve stable gutters, test the packaged WebView at high DPI, and retain a reduced-motion path | Mitigated M9; ongoing accessibility regression coverage required |

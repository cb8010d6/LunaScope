# LunaScope 0.1.0

**The Moonwatcher Project · 望月者计划**

LunaScope 0.1.0 is the first public engineering preview of the Windows desktop agent workbench.

## Included

- Native Tauri 2 desktop application and Rust execution core
- Durable projects, conversations, context summaries and recovery
- Single-agent and automatically orchestrated multi-agent execution
- OpenAI, Anthropic, DeepSeek and compatible provider configurations
- Bounded filesystem, process, browser, Skill, MCP and LunaScope-management tools
- Isolated worktrees, patch handoff, targeted retry and independent verification
- Criterion-level acceptance evidence and automatic fatal-defect repair chains
- Dynamic Codex/Claude-compatible Skills and commit-pinned GitHub Skill import
- UltraNote projects, Office/PDF ingestion, interactive notes, Mermaid, mathematics and PDF export

## Artifacts

- `LunaScope_0.1.0_x64-setup.exe` — Windows x64 NSIS installer
- `lunascope-desktop.exe` — portable Windows x64 executable
- `SHA256SUMS.txt` — SHA-256 checksums for both binaries

## Important release notes

- The binaries are unsigned and may trigger Windows SmartScreen.
- Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required.
- Provider credentials are not bundled. Add them through LunaScope's masked native settings flow.
- HarmonyOS Sans SC is referenced from the local Windows font installation and is not redistributed.
- Imbad0202 academic research Skills are CC BY-NC 4.0 and are not cleared for commercial redistribution.
- LunaScope's own distribution license has not yet been selected.
